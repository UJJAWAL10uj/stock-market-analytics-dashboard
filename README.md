# stock-market-analytics-dashboard
## Stock Market Feature & Funnel Analytics

Analysed NSE top 5 stocks (2023–2024) using yfinance — calculated 
annualised returns, volatility, and Sharpe ratios. Built a simulated 
10,000-user trading app funnel to identify drop-off points and proposed 
an AI-powered trade recommendation feature to improve KYC-to-first-trade 
conversion from 28% to 38%.

**Tools:** Python, SQL, yfinance, pandas, numpy, HTML/CSS/JS  
**Dashboard:** Open stock_analytics_dashboard.html in any browser
